# Project Vision

> 本文是项目的"宪法",应保持稳定,不随日常迭代频繁修改。

## 1. 项目定义

本项目是一个面向个人成长与教育规划场景的长期 AI 智能体系统。

它不是传统 Todo List,也不是简单的 AI 学习规划工具。

系统围绕用户真实成长过程建立闭环:

```
Understand → Plan → Execute → Sense → Replan → Grow
```

AI 不仅帮助用户制定计划,还持续理解用户目标、现实约束、执行状态和行为变化,并据此动态调整成长路径。

## 2. 核心问题

传统规划工具通常存在三个断裂:

### 规划与用户理解断裂

计划往往由一次输入生成,缺少持续沟通。

### 规划与执行断裂

系统知道"用户应该做什么",却不知道"用户实际上做了什么"。

### 执行与调整断裂

现实发生变化后,原有计划很快失效,却没有持续 Replan。

## 3. 核心产品闭环

```
用户目标
   ↓
AI 理解用户
   ↓
构建 Growth Space
   ↓
形成成长路径
   ↓
拆解计划
   ↓
用户执行
   ↓
App / 用户反馈感知执行状态
   ↓
发现偏差
   ↓
AI Replan
   ↓
Growth Space 更新
   ↓
沉淀成长资产
   ↓
进一步理解用户
```

## 4. 核心产品理念

### 4.1 Plan is a Living State

计划不是 AI 输出的一篇 Markdown。

计划是一份持续变化的结构化状态。

### 4.2 Conversation ↔ Growth Space

用户通过自然语言与 AI 共同构建计划。

用户也可以直接操作 Growth Space。

两种方式具有同等地位。

### 4.3 One State, Many Views

Graph / Timeline / Plan / Today

不是不同计划。

它们是同一 Growth State 的不同投影。

### 4.4 Reality Drives Replanning

用户没有按照计划执行并不意味着系统失败。

执行偏差本身就是新的信息。

系统应该:

```
Sense → Understand → Replan
```

## 5. 双端定位

### Web

**Think & Plan**

负责:

- 深度对话
- Growth Space
- Graph
- Timeline
- Plan
- 长期规划
- 深度分析

### Mobile

**Act & Sense**

负责:

- Today
- 当前任务
- AI 陪伴
- 快速记录
- 随笔
- 执行反馈
- 行为感知
- 主动提醒

## 6. 一句话定义

我们不是替用户制定一份完美计划。

我们希望构建一个能够与用户共同规划、理解现实变化,并在一次次偏离之后重新寻找前进路径的长期成长智能体。
