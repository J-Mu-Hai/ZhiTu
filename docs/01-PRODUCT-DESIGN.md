# Product Design

## 1. Target User

MVP 阶段主要用户:

大学生。

典型需求包括:

- 保研
- 考研
- 科研
- 就业
- 技能成长
- 比赛
- 项目
- 自我提升

## 2. Core Product Loop

```
Goal → Understand → Plan → Execute → Sense → Replan → Grow
```

## 3. Core Modules

### Home / Today

回答:

> "我现在最应该做什么?"

包含:

- 当前核心目标
- 今日任务
- 今日完成情况
- AI Insight
- 快速对话

### Growth Space

回答:

> "我要去哪里,以及怎么去?"

包含:

- Graph View
- Timeline View
- Plan View
- Conversation Layer

详见 [03-GROWTH-SPACE.md](03-GROWTH-SPACE.md)。

### Journal

低压力记录入口。

内容可以成为:

- User Memory
- Growth Event
- User Profile Signal
- Growth Asset

### Growth

呈现长期变化:

- Growth Report
- Milestone
- Growth Assets
- Execution Trend
- Behavior Pattern

### Me

包含:

- User Profile
- AI Memory
- Behavior Data
- Settings

## 4. AI Proactivity

四档:

- Passive
- Companion
- Coach
- Strict

用户可以控制:

- 主动聊天
- 提醒频率
- 是否允许批评
- 是否允许 AI 调整计划
- 是否提醒休息

## 5. Product Principle

AI 主动联系用户必须存在原因。

避免:

> "今天也要加油!"

优先:

> "你原计划今晚完成论文阅读,但距离结束时间还有 90 分钟,目前尚未开始。需要调整计划吗?"
