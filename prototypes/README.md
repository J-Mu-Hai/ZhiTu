# prototypes

一次性原型与探索性实验。**这里的代码不接入生产** —— `apps/` 与 `backend/` 不得引用本目录。

| 目录 | 用途 |
| --- | --- |
| [mother-demo/](mother-demo/) | 完整走通主流程的可演示原型,用于验证体验假设 |
| [ui-experiments/](ui-experiments/) | 视觉与布局实验 |
| [interaction-experiments/](interaction-experiments/) | 交互方式实验(对话流、时间轴、拖拽等) |

每个原型自带 README,说明:想验证什么假设、怎么跑、结论是什么。
验证完的结论应回写到 `docs/`,而不是留在原型里。
