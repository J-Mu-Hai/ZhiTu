# 知途 · Demo 2

独立的 frontend-only 体验原型。所有实现留在本目录，不被正式应用引用，不调用后端、数据库或真实 AI。

## 启动

需要 Node.js 22 或更新版本。

```powershell
cd prototypes/demo2
npm install
npm run dev
```

打开 http://127.0.0.1:3102 。默认进入工作台。

```powershell
npm run lint
npm run typecheck
npm run build
npm start
```

浏览器交互验证：`npm run test:e2e`。默认使用本机 Chrome；其他安装位置可设置 `CHROME_PATH`。测试截图写入被 Git 忽略的 `artifacts/`。

## 演示流程

1. 在路径视图拖动画布、缩放、拖动节点；点击「科研能力」或「联系导师」，观察右侧上下文。
2. 切换时间线，点击「科研项目」。拖动任务条到 12 月，或用底部「编辑日期」设置 2026-12-01 至 2027-01-11。
3. 右侧出现本地冲突建议。点击「查看影响」突出科研项目与核心课程；点击「接受调整」，项目移至 2027-01-18 至 2027-02-28。
4. 切换任务，选择今天／本周／本阶段，勾选任务完成；返回路径查看同步状态。
5. 发送一条消息，体验选中对象驱动的 Mock 对话。输入区固定，历史单独滚动。
6. 双击任意节点（或点击悬浮箭头）进入它的空间，节点自动成为母节点。用面包屑返回上级；新建节点后可继续进入，无预设层级限制。
7. 点击「空间文件」选择或拖入文件。图片与文本可以预览，其他格式可下载。文件归属当前节点，不会出现在兄弟空间中。
8. 首页可以启动／暂停专注、完成学习和查看安排说明。随笔支持发布、图片、标签和关联成长对象。
9. 对话中心可以搜索、切换、新建和继续历史讨论；关联对象可进入工作台。保研对话与工作台面板共享历史。
10. 我的包含档案、画像、周／月／阶段报告、资产、行为、记忆和设置。设置在页面切换后保留，行为页读取本次实际任务与专注数据。

## 数据边界

- `src/mock/growth-state.ts` 是唯一计划种子；固定体验日期为 2026-09-16。
- `DemoProvider` 挂在根布局，跨页面保留内存状态。刷新重置。
- 本地文件只保存在本次浏览器会话，不上传；刷新也会清除。上传区会明确提示。
- `spaceId` 决定当前空间，子空间不是独立计划副本。任务和时间线按当前节点及后代过滤。
- 领域修改统一通过 `PlanAction` 与 reducer；画布坐标单独存储。
- Task、Milestone 使用同一节点集合；对话通过节点 ID 引用对象。
- 类型仅服务原型，不声明兼容仓库当前 `shared/schemas/`。正式接入时需明确迁移。
- Mock 回复不会任意理解自然语言或自动执行修改；时间调整建议需要用户接受。

完整范围与设计见 `docs/demo-design.md`。

## Demo 2 布局

从 mother-demo 独立复制，原版保持不变。使用端口 3102，可与原版同时运行。

- 左侧导航迁至 46px 顶栏；个人中心二级入口也在顶部。
- 工作台画布占满可用宽度，可无限平移，缩放与递归空间沿用原版。
- 对话面板悬浮在画布右侧，拖动左下角调整宽高；聚焦手柄后可用方向键微调。
- 关闭或缩放对话面板不改变画布尺寸，重新打开保留本次工作台内的尺寸。
- 深墨绿底色搭配低饱和分类色，保留原有数据与交互。
